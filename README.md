## 🍿 주요 기능

1. **시네마틱 다크 모드 & 앰비언트 라이트**
   - 어두운 영화관의 무드를 담은 딥 블랙 & 시네마 레드 컬러 시스템
   - 상단 영사기 빔 애니메이션과 마우스 호버 시 글래스모피즘 & 네온 글로우 효과
   - 모바일 & PC 반응형 레이아웃

2. **장르별 영화 분류 (12편의 엄선작)**
   - `전체`, `액션`, `코미디`, `SF`, `스릴러`, `로맨스`, `애니메이션` 실시간 필터링
   - 인터스텔라, 인셉션, 기생충, 범죄도시, 극한직업, 라라랜드, 어벤져스: 엔드게임, 코코, 부산행, 타이타닉, 스파이더맨: 노 웨이 홈, 월터의 상상은 현실이 된다
   - 포스터 이미지 로딩 실패 시 자동 대체 슬레이트 폴백 지원

3. **오늘의 랜덤 영화 추천 (시네마 티켓 모달)**
   - 원클릭으로 랜덤 영화를 영화관 티켓 형태로 발권하는 듯한 팝업 제공
   - 평점, 상영관, 추천 명당 좌석, 러닝타임, 줄거리, 바코드 및 펀치홀 디테일
   - 다른 영화 다시 추천받기 기능

4. **영화 간식 룰렛 (10가지 간식)**
   - 팝콘, 나초, 핫도그, 감자튀김, 치킨, 피자, 초콜릿, 젤리, 아이스크림, 콜라
   - HTML5 Canvas 기반 정밀 물리 감속 애니메이션
   - 바늘 위치와 당첨 결과 100% 일치
   - Web Audio API 내장 틱틱틱 사운드 & 팡파르, 축하 콘페티 효과

## 🚀 실행 방법

별도의 서버 설치 없이 브라우저에서 `index.html`을 바로 열어 실행할 수 있습니다.

```bash
# 로컬 테스트 서버 실행 (선택)
node server.js
# 브라우저에서 http://localhost:3000 접속
```
